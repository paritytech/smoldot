Struct PeerSteering 

Source 
pub struct PeerSteering<TNow> { /* private fields */ }
Expand description

Keeps the reserved statement peers aligned with the peers needed to cover the subscribed topics.

The connected set is fed by the statement substream events, the needed and reserved sets by the caller.

pub fn peers_to_release(&self) -> Vec<PeerId>

Reserved peers no longer needed. A peer without an open substream is released at once. The connected ones go at most a fifth of the connected peers per refresh, and at least one, so that the set converges step by step. The longest-connected peers go first, spreading the disconnects across peers.
