# WebTransport certificate vectors

`cert_vector.json`: the DER certificate and its SHA-256 hash that PolkaJam
presents for validators 0 and 1 of its development network, each for the
ten-day periods 2072 and 2073, with the validator's P-256 peer identity in
text form. Generated by a test calling PolkaJam's own certificate code
(`net/cert.rs`, rcgen 0.14.8) at PolkaJam
`e5b3318f22e9de1120d203d8eb4b0757c4a4a357`.

PolkaJam's own vector, `web_transport_cert_vector` in `net/cert.rs`, is the
test `polkajam_certificate_vector` in `../tests.rs`.
